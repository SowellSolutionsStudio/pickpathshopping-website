Support & FAQs

A little help for your next trip, plus a direct way to reach the PickPath team.

Need assistance? Email studio@sowellsolutions.com. Describe the issue and your device, but please don't send passwords or private backup files unless we specifically agree on a safe way to review them.

Common questions

How does PickPath learn my store?

Choose a store, create a list, and use Learning Mode while shopping to record where items are found. On later trips, known items can follow that learned order. New items may need to be placed first.

Does PickPath work offline?

Yes. The installed Android app is designed to work without an ongoing network connection for core lists and routes. Internet access may be needed for app installation, updates, or sharing exported backups through online services.

Where is my shopping data stored?

In the current release, shopping data lives locally on your device. There is no required account and no automatic household synchronization.

How do I back up my lists?

Open Settings and choose Export Backup. Save or share the generated JSON file in a safe location. Backups are manual, so repeat this whenever you want a newer copy.

Can I transfer lists to another phone?

Yes. Export a backup from one installation and use Import Backup on the other. Important: the import replaces the receiving phone's existing shopping database rather than merging changes. Back up the receiving phone first if you need its existing data.

Is Family Sync available?

Not yet. Live, shared household synchronization is a planned future feature. Current backups are a manual transfer option, not automatic synchronization.

What happens if I uninstall the app?

Uninstalling or clearing application data can erase locally stored lists and routes. Export a backup first if you want to keep them.
