# PickPath Shopping website

Official public website for PickPath Shopping. Built as a lightweight, accessible static site on GitHub Pages.

## Preview and launch

The website is designed for deployment from the repository root (`main` branch). Review the GitHub Pages project URL before connecting `pickpathshopping.com` through Cloudflare. The published site will expose the homepage plus `/privacy/`, `/terms/`, and `/support/`.

The app is developed by Sowell Solutions Studio and operated by Sowell Solutions LLC.

## Maintenance

Legal pages and the application's in-app legal copy must remain in sync before Google Play submission. Verify all feature claims and support contact details before publishing. Avoid analytics, trackers, or third-party embeds without updating the privacy policy.
